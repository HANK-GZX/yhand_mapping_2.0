# 左拇指 V4 线性遥操

V4 是原 `combo_linear` 的正式版本名，沿用相同的拟合系数。它将 12 个采集 combo 的组内运动合成一套 6×4 矩阵。遥操时输入 Manus 的四个相对角，六台电机都由同一套矩阵计算位置目标。采集 combo 标签用于训练分组。

## 训练数据

使用 `scripts/motor_test_logs/data_collection/thumb_data` 的左拇指配对数据。输入为左侧手套 `glove48[8:12]` 的四个角，其中 q0、q1 描述根部姿态，q2、q3 分别为近端、末端指节弯曲。输出为 M4、M6、M7、M8、M14、M27 的实际位置反馈。每个采集点用结果窗口的均值计算。

训练使用 8,149 个正式点。其中 5,023 个到位，3,126 个超时。超时点保留实际反馈，单电机预采点排除。12 个 combo 来自三种主动伸屈（长屈、短伸、长伸）、两种侧摆（内收、外展）和两种对掌采集标签（`opp_on`、`opp_off`）。`opp_off` 是采集标签，组内仍包含 M14 反馈。

## 两阶段拟合

1. **拟合各组斜率。** 对每个 combo 分别做带截距的约束最小二乘拟合。设该组的角度、位置均值分别为 `q̄_c`、`m̄_c`，拟合得到 6×4 矩阵 `B_c`，组内预测为 `m̂ = m̄_c + B_c × (q − q̄_c)`。伸屈与 q0 侧摆约束适用于全部组合，对掌的 q1 约束仅用于 `opp_on` 组。
2. **合成公共斜率。** 对各组取 `x = q − q̄_c`，使用该组模型生成电机位移 `y = B_c × x`，再用一次约束最小二乘拟合共同关系 `y ≈ B × x`。各组截距在这一步被去掉。每个样本的权重为 `1/该组样本数`，因此各组对合成目标的总权重相同。公共矩阵使用下表的全部约束。

电机位置增量向正表示放线，向负表示收线。约束描述其余三角固定时的响应，多个角同时变化时，各项相加。

| 输入或输出 | 公共矩阵的约束 |
| --- | --- |
| q2、q3 各自增大 | M4 长屈收线或保持，M6 短伸、M7 长伸放线或保持。 |
| q0 增大 | M8 内收放线或保持，M27 外展收线或保持。 |
| q1 减小 | M14 对掌、M4 长屈收线或保持，M6、M7、M8、M27 放线或保持。 |
| M14 对掌的轴优先级 | q1 系数非负，且大于或等于其他任一单轴系数的绝对值。 |

## 发布矩阵与运行坐标

Manus 模式按操作员启动姿态计算 `Δq`，并计算 `m_target = B × Δq`。四角变化为零时六路位置目标均为零。表内数值为每关节度对应的电机度，运行时读取 JSON 的完整精度。

| 电机 | Δq0 | Δq1 | Δq2 | Δq3 |
| --- | ---: | ---: | ---: | ---: |
| M4 长屈 | 1.0674 | 2.2029 | −1.4212 | −1.7094 |
| M6 短伸 | 2.1003 | −3.7587 | 2.0074 | 0.0000 |
| M7 长伸 | 1.3150 | −4.3850 | 2.4722 | 1.0877 |
| M8 内收 | 3.6145 | −1.6060 | 0.8726 | 0.2635 |
| M14 对掌 | 1.7444 | 6.1852 | −0.0368 | 0.2844 |
| M27 外展 | −2.6016 | −1.7573 | 0.3875 | −0.5559 |

拟合为 M6 保留了 q2 项，q3 系数落在约束边界 0。M8 和 M27 共用 q0 侧摆与 q1 对掌补偿。绝对角输入时使用与 V3 相同的采集参考 `[8.491, 38.262, 26.028, −26.219]°` 计算 `Δq`。

M14 的启动阶段沿用 V3。目标相对初始反馈偏移达到 10 电机度后，执行 1 秒有界启动和 1 秒平滑交接，之后直接跟随实时目标。上表给出模型目标，启动阶段实际下发位置由启动轨迹计算。

## 验证与复算

分块五折按各组 `point_id` 顺序划分。每折只用训练点重拟合两阶段模型。另将 12 个 combo 依次整组留出，检查新组合上的表现。下表汇总各采集组合记录中的主动位置控制路，误差单位为电机度。

| 离线评估 | MAE |
| --- | ---: |
| V4 分块五折，预测原反馈位置 | 7.13 |
| V4 分块五折，使用各组同一实测锚点 | 7.51 |
| 原版 V3 配置回放，使用相同实测锚点 | 8.52 |
| V4 留一组，预测原反馈位置 | 7.60 |

原反馈位置评估使用训练数据估计一个常量偏移。锚点评估使用 `m_anchor + B × (q − q_anchor)`，两种评估用来比较采集坐标中的预测。Manus 运行时使用启动零位。原版 V3 曾在同批数据上拟合，表中的 V3 数值是配置回放。逐电机 MAE、P95、R²、数据哈希和系数保存在 [V4 模型 JSON](config/experiments/left_thumb_linear_v4.json)。

在保留离线拟合脚本和采集数据的本地工作空间，可以从仓库根目录执行下面的命令复算。
发布仓库提供运行用模型和拟合说明。复算默认加载经过点日志与 point_id 核对的缓存。
追加 `--refresh-cache` 可重读采集工作簿，需安装 openpyxl。拟合使用 NumPy 和 SciPy。

```bash
python3 "src/yhand_mapping/scripts/q_2_m linear mapping/fit_left_thumb_linear_v4.py"
```

## 实机电机跟踪

2026-11-18 11:05 的左拇指 V4 日志 `20261118_110532_143227` 共运行约 68 秒，正常退出。六路
电机反馈错误码均为 0，50 Hz 下发没有跳周期。M14 在 8.14 秒进入启动柔化，10.14 秒进入直接跟随。

快速动作拉高了误差。将较早约 120 毫秒的指令与当前反馈对齐，M7 的 MAE 从 37.91 降至
14.42，M14 从 35.00 降至 11.88。该对齐方法估算本段的运动响应滞后。同期电机反馈消息年龄
最大 17.70 毫秒。M14 在直接跟随时最大单帧目标变化为 89.04 电机度，出现在 60.72 秒。

33.26 秒附近，M7 的收线指令达到 −122.52°，编码器为 −13.84°，电流为 −0.489 A。
同一段内，M7 和 M6 的电流分别最低到 −0.499 A 和 −0.496 A，均接近本次驱动的 0.5 A 上限。
这段表现出负向收线欠跟踪。日志未记录机器人关节角和肌腱张力，能评估编码器跟踪，
暂无法量出 q0～q3 的机器人关节跟踪误差或确定实际收线负载来源。

## 启动遥操

```bash
source install/setup.bash
ros2 launch yhand_mapping left_hand_q_to_motor_launch.py \
  finger:=thumb input_mode:=2 model:=linear thumb_version:=v4
```

五指模式使用 `finger:=five`，V4 只应用于拇指。已有 Manus 发布节点时可追加 `start_glove_node:=false`。V4 与 `model_file` 及实测路径参数 `thumb_combo_calibration` 互斥。
